# تحليل أسعار الأسهم وتقدير اتجاهاتها

تطبيق لاستكشاف أسعار الأسهم وبناء تقديرات طويلة الأجل، مع إدخال مؤشرات اقتصادية إلى جانب تاريخ السعر.

[فتح التطبيق](https://xvaxbbzdgb2rhdxylpn9ez.streamlit.app/)

## ما يقدمه
- تقدير مستهدف سعري على أفق يصل إلى خمس سنوات.
- جلب بيانات السوق والمؤشرات الاقتصادية بحسب توافر مصادرها.
- نماذج تعلم عميق تشمل الشبكات الالتفافية وشبكات الذاكرة طويلة المدى.
- عرض سيناريوهات متفائلة ومتشائمة للمساعدة على فهم نطاق التقديرات.

## المدخلات
يصف المشروع 11 متغيرًا، تشمل سعر الإغلاق، والفائدة، والتضخم، والناتج المحلي، والبطالة، ومؤشر تقلب السوق، وأداء مؤشر السوق العام، إضافة إلى مؤشرات مالية محسوبة.

هذه تقديرات ناتجة عن نماذج؛ وجود أفق زمني طويل أو سيناريوهات متعددة لا يضمن صحة التوقعات.
